# 책 속 사진 — 사진함과 자동 배치, 의도 지정

- 날짜: 2026-10-12
- 상태: 방향 승인됨(① 의미 지정 + ③ 틀, 쪽 좌표 고정은 두지 않음. 출시: A+B 첫 출시, C 나중). 규격 초안, 검토 대기
- 상위 기획: `docs/specs/2026-10-11-book-service-design.md` (이 문서가 그 6.4 이미지를 대신하고 10.1 Book JSON을 넓힌다)
- 관련: `docs/specs/2026-10-12-book-markup-design.md` (4.2 그림 표기, 7절 점검, 8.1 대응을 넓힌다)
- 목업: `apps/book-mockup/index.html`

## 1. 목적

작가가 사진을 넣기만 하면 미리보기에서 자연스러운 배치를 확인하고 끝낼 수 있게 한다.
의도를 가지고 놓고 싶을 때는 조판 용어나 좌표 없이 "이 사진은 크게", "글 옆에", "이 문단 뒤로" 정도의 말과 끌기로 할 수 있게 한다.

## 2. 사진 밀도 세 수준

| 수준 | 예 | 배치의 중심 | 출시 |
|---|---|---|---|
| A. 글 중심 + 사진 가끔 | 자서전, 에세이, 소설 속 삽화 | 글 흐름 속 사진 한 장씩. 자리가 없으면 미루기 | 첫 출시 |
| B. 글과 사진 반반 | 여행기, 가족 문집 | 여러 장 묶음(흐름 틀), 한 면·펼침면 사진, 글 두르기 | 첫 출시 |
| C. 사진책 | 사진집, 앨범형 책 | 면 단위 틀에 사진을 채우고 글은 설명 | 나중 (규격만, 7절) |

공통 바닥(사진함, 원고와 연결, 해상도, 중심점)은 하나이고 배치 방식만 수준별로 다르다.

## 3. 원칙

1. **의미로 저장한다.** 배치는 쪽 좌표가 아니라 앵커(앞 문단)와 말(크기, 자리, 틀)로 저장한다. 원고를 고쳐 쪽이 밀려도 사진은 자기 이야기를 따라간다.
2. **정하지 않은 것은 저장하지 않는다.** 크기·자리·틀이 비어 있으면 조판기가 고른다(자동). 값이 있으면 작가의 의도다.
3. **끌기는 말로 번역한다.** 미리보기에서 끌어 놓을 수 있는 곳은 정해진 자리뿐이고, 놓으면 1의 말로 저장한다. 자유 좌표는 없다.
4. **자동이 한 일을 보여 준다.** 무엇을 왜 골랐는지, 어디로 미뤘는지 사진 카드와 점검에서 말한다.
5. **의도를 조용히 버리지 않는다.** 지킬 수 없으면 가장 가까운 배치로 놓고 알린다.

## 4. 사진함 — 이 책의 사진

### 4.1 들어오는 길

책마다 사진함이 하나 있다. 어느 길로 들어와도 사진함에 모인다.

| 길 | 원고에 |
|---|---|
| 편집기의 "사진" 버튼 또는 파일 끌어 놓기 | 커서 자리에 들어간다 |
| 사진함에 여러 장 올리기 | 아직 넣지 않는다 ("아직 안 씀") |
| 워드(.docx)에 든 사진 | 그 자리에 들어간다 |
| 원고에 `[그림: 이름]`만 있고 사진이 없음 | 빈 "사진 자리"(G1). 같은 이름의 사진을 올리면 자동으로 채운다 |

### 4.2 원고와 연결

- 원고의 사진 블록은 파일이 아니라 사진함 항목 id(`asset`)를 가리킨다. 표기의 파일 이름은 사진함 안의 이름으로 찾는다.
- 이름이 겹치면 `부엌 (2).jpg`처럼 자동으로 바꾼다.
- **사진 바꾸기:** 자리·설명·배치는 두고 파일만 바꾼다(id가 가리키는 파일 교체). 해상도 경고를 고칠 때 쓴다.
- **지우기:** 원고에 쓰인 사진이면 "원고의 사진 자리도 지울까요?"를 묻는다.

### 4.3 사진함 화면 (작업실 왼쪽, 차례 옆 탭)

- 썸네일 격자. 사진마다 쓰인 곳("3장 · 18쪽") 또는 "아직 안 씀". 누르면 그 자리로 간다.
- 원고나 미리보기로 끌어 넣는다(앵커는 놓은 자리).
- 여러 장을 골라 "원고에 넣기"를 누르면 고른 자리 하나에 사진 묶음으로 들어간다. 찍은 날짜순 정렬을 고를 수 있다.

### 4.4 손질 — 최소한, 원본 보존

- 돌리기, 중심점(틀이나 면에 맞춰 잘릴 때 보일 곳). 원본 파일은 바꾸지 않는다.
- 색 보정·필터는 두지 않는다.

### 4.5 파일

- JPEG, PNG, HEIC를 받는다. 서버가 원본과 미리보기용 작은 사본을 보관하고, EXIF 회전을 반영한다.
- 색은 RGB 그대로(상위 기획 6.4의 흑백 미리보기 토글은 유지).
- 해상도(dpi)는 놓인 크기가 정해진 뒤 계산한다(8절 G3).
- 휴대폰에서 QR로 바로 올리기는 나중.

## 5. 원고 속 표현

### 5.1 사진 하나

`[그림: 파일 | 설명 | 크기와 자리]` — 책 표기 4.2를 넓힌다.

```
[그림: 바다.jpg | 버스 창문으로 본 남해]                  ← 크기·자리 자동
[그림: 부엌.jpg | 할머니의 부엌 | 반 폭, 글 옆]           ← 의도 지정
[사진: 항구.jpg | | 펼침면]                               ← '사진:'도 받음. 정규형은 '그림:'
```

- 셋째 칸은 쉼표로 나눈 말을 순서 없이 받는다.
  - **크기:** `본문 폭`, `반 폭`, `한 면`, `펼침면`
  - **자리:** `그 자리`, `쪽 위`, `쪽 아래`, `글 옆`, `글 옆 왼쪽`, `글 옆 오른쪽` (`글 옆`은 바깥쪽)
  - **한 면의 채움:** `종이 끝까지` (없으면 여백 안)
- 크기를 생략하면 **자동**이다(지금까지는 본문 폭이었다).
- 사진은 바로 앞 문단에 붙는다(앵커). 장 첫머리의 사진은 장 시작에 붙는다.

### 5.2 사진 묶음

```
::: 사진 묶음 | 나란히
[그림: 장터1.jpg | 생선 좌판]
[그림: 장터2.jpg | 국밥집]
읍내 오일장, 1987년 여름
:::
```

- `| 틀`은 생략할 수 있다(자동). 흐름 틀 이름은 6.4.
- 안에는 사진 줄과 설명 줄만 둔다. 사진이 아닌 줄은 묶음 전체의 설명이다(여러 줄이면 이어 붙인다).
- `::: 사진 묶음`은 모양 사전의 상자 이름이 아니다. 별칭: `::: 사진들`, `::: 묶음`.
- 사이에 글 없이 연달아 놓인 사진 줄은 표기 없이도 묶음으로 조판한다(6.3). 저장은 사진 블록 그대로 둔다.

### 5.3 배치 지시 (책 표기 4.4에 추가)

| 표기 | 뜻 | 받아 주는 변형 |
|---|---|---|
| `[새 펼침면]` | 다음 펼침면(왼쪽 면)에서 시작 | `[펼침면에서]` |

### 5.4 Book JSON (상위 기획 10.1, 책 표기 8.1을 넓힘)

```jsonc
{
  "meta": { ... },
  "design": { ..., "photoScale": "normal" },          // 작게 small / 보통 normal / 크게 large (9.1)
  "assets": [
    { "id": "a7", "name": "부엌.jpg", "w": 4032, "h": 3024, "rotate": 0,
      "takenAt": "1987-07-02", "focus": [0.5, 0.35], "src": "…" }
  ],
  "sections": [ { ..., "blocks": [
    { "type": "image", "asset": "a7", "caption": "할머니의 부엌",
      "size": "half", "place": "side", "side": "outer" },          // 작가가 정한 것만 저장
    { "type": "gallery", "frame": "row", "caption": "읍내 오일장, 1987년 여름",
      "items": [ { "asset": "a8", "caption": "생선 좌판" }, { "asset": "a9" } ] },
    { "type": "directive", "kind": "newSpread" }
  ] } ]
}
```

| 필드 | 값 |
|---|---|
| `size` | `body` 본문 폭, `half` 반 폭, `page` 한 면, `spread` 펼침면. 없으면 자동 |
| `place` | `inline` 그 자리, `top` 쪽 위, `bottom` 쪽 아래, `side` 글 옆. 없으면 자동 |
| `side` | `outer`(기본), `left`, `right`. `place: "side"`일 때만 |
| `bleed` | `true`면 종이 끝까지. `size: "page"`일 때만 저장. `spread`는 늘 종이 끝까지 |
| `frame` | 흐름 틀 `row` 나란히, `grid` 격자, `hero` 큰 하나. 면 틀 이름(7절). 없으면 자동 |

- 상위 기획 10.1의 `src: "asset://…"`는 `asset` id로 바꾼다. 상위 기획의 `size: "full"`은 `"page"`로 바꾼다.
- 중심점(`focus`)은 사진함 항목에 둔다. 같은 사진은 어디에 쓰여도 같은 곳이 보인다.
- 왕복 성질 P1·P2(책 표기 8.3)를 지킨다. 자동 값은 저장하지 않으므로 표기에도 나오지 않는다. 정규 표기에서 셋째 칸은 크기 → 자리 → `종이 끝까지` 순서로 쓴다.

## 6. 자동 배치 (A·B)

조판기가 크기와 자리를 고른다. 작가가 정한 값은 그 값만 지키고 나머지 규칙은 같다.

### 6.1 크기 고르기 (크기가 비어 있을 때)

| 사진 | 크기 |
|---|---|
| 가로 사진, 본문 폭에서 300dpi 이상 | 본문 폭 |
| 세로 사진 (세로 ≥ 가로 × 1.2) | 반 폭 |
| 본문 폭이면 300dpi 미만, 반 폭이면 300dpi 이상 | 반 폭 |
| 반 폭에서도 150dpi 미만 | 반 폭 + 점검 경고(G3) |

- 자동은 한 면·펼침면을 고르지 않는다. 예외는 "장의 첫 가로 사진 크게"(6.6)와 사진 크기 `크게`(9.1).
- 사진 크기 `작게`이면 가로 사진도 반 폭을 고른다.

### 6.2 자리 고르기

1. 기본은 **그 자리**(앵커 문단 바로 뒤).
2. 남은 높이가 모자라면:
   - ⓐ 크기를 자동으로 고른 사진이면 85%까지 줄여서 넣는다.
   - ⓑ 그래도 안 되면 다음 쪽 맨 위로 미루고, 빈 곳은 뒤 문단으로 채운다. 원고 순서와 어긋나는 거리는 한 쪽까지.
3. 소제목과 그 뒤 문단 첫 2줄 사이에는 놓지 않는다. 설명은 사진과 같은 쪽에 둔다.
4. 자동 사진은 한 쪽에 최대 2장(여행 프리셋 3장). 넘치면 다음 쪽으로.
5. 장 시작 면에는 자동으로 놓지 않는다. 앵커가 장 시작인 사진(장 첫머리에 넣은 사진)만 장 제목 아래 그 자리에 놓는다.
6. 반 폭 사진의 자동 자리는 프리셋이 정한다(6.6): 가운데, 또는 옆 글이 충분하면 글 옆.

### 6.3 저절로 묶기

사이에 글 없이 연달아 놓인 사진 블록은 묶음으로 조판한다(틀 자동). 크기를 정한 사진이 섞여 있으면 묶지 않는다.

### 6.4 흐름 틀 (묶음)

| 틀 | 모양 | 비고 |
|---|---|---|
| `나란히` (자동) | **높이 맞춘 줄**: 비율을 지킨 채 한 줄의 사진을 같은 높이로 맞춰 본문 폭을 채운다. 줄 높이가 본문 높이의 1/4~1/2이 되게 줄을 나눈다 | 자르지 않음. 가로·세로가 섞여도, 몇 장이어도 됨 |
| `격자` | 같은 크기 칸, 한 줄에 2장(5장 이상이면 3장). 칸 비율은 4:3 | 중심점으로 자름 |
| `큰 하나` | 첫 사진 본문 폭 + 나머지를 높이 맞춘 줄로 | |

- 줄 하나는 쪽을 넘기지 않는다. 줄과 줄 사이에서 쪽이 나뉠 수 있다. 묶음 설명은 마지막 줄 아래.
- 사진별 설명은 사진 아래 작게. 줄 안에서 설명 높이는 가장 긴 것에 맞춘다.

### 6.5 의도로만 쓰는 배치

| 배치 | 규칙 |
|---|---|
| 글 옆 | 사진 폭은 본문의 40%, 기본은 바깥쪽. 이어지는 문단이 사진 옆을 좁은 폭으로 흐르고, 사진 아래부터 본문 폭. 옆 글이 12자보다 좁아지면 그 자리에 가운데로 놓고 G6 |
| 쪽 위 / 쪽 아래 | 앵커가 놓인 쪽의 위·아래. 앵커 쪽에 자리가 없으면 다음 쪽 위 |
| 한 면 | 앵커 뒤 다음 면 전체. 앞 면 남은 자리는 글로 채운다. `여백 안`(기본)은 본문 영역 안에 맞추고 설명은 아래, `종이 끝까지`는 재단 여백까지 채운다 |
| 펼침면 | 앵커 뒤 다음 펼침면(왼쪽 짝수 면 + 오른쪽 홀수 면), 종이 끝까지. 사이 면은 글로 채운다. 가운데 약 5mm가 제본으로 접혀 들어감을 사진 카드에서 안내 |

- 한 면·펼침면 사진이 놓인 면은 머리글·쪽 번호를 숨긴다. 종이 끝까지 사진의 설명은 아래 여백 띠에 작게, 펼침면은 오른쪽 면에.
- 펼침면 때문에 빈 면이 생기거나(장 끝 등), 한 면 사진이 장 시작 면에 걸리면 한 면으로 바꾸거나 다음 면으로 미루고 G4.

### 6.6 프리셋별 사진 기본값

| | 에세이 · 소설 | 실용 | 여행 (새 프리셋) |
|---|---|---|---|
| 반 폭 자동 자리 | 가운데 | 가운데 | 글 옆 (옆 글이 충분할 때) |
| 쪽당 자동 사진 | 2 | 2 | 3 |
| 설명 | 아래, 작게 | 아래, "그림 3-2" 번호(장마다) | 아래, 작게 |
| 장의 첫 가로 사진 크게 | 끔 | 끔 | 켬 (한 면, 종이 끝까지) |
| 한 면 기본 채움 | 여백 안 | 여백 안 | 종이 끝까지 |
| 본문 서체 · 크기 | 상위 기획 6.6 | 상위 기획 6.6 | 명조 10pt / 165%, 문단 사이 간격, 같은 면 시작 |

**여행 프리셋**은 상위 기획에서 "나중에"였으나 B가 첫 출시이므로 첫 출시로 옮긴다. 모양 사전 기본값은 에세이와 같게 시작한다.

## 7. 사진책 (C) — 규격만

### 7.1 두 종류의 틀

| | 흐름 틀 (B, 첫 출시) | 면 틀 (C, 나중) |
|---|---|---|
| 단위 | 글 사이의 묶음 (폭 = 본문 폭) | 한 면 또는 펼침면 전체 |
| 사진 | 비율 유지(격자만 자름) | 칸 비율에 맞춰 자름 (중심점) |
| 틀 | `나란히`, `격자`, `큰 하나` | `한 장 가득`, `한 장 + 여백`, `둘 나란히`, `큰 하나 + 둘`, `넷 격자`, `펼침면 가득`, `왼쪽 글 · 오른쪽 사진` … 프리셋마다 목록 |

면 틀은 칸 목록(면 안의 비율 좌표, 왼/오른쪽 면, 종이 끝까지 여부, 설명 칸)이다. 실제 모양은 프리셋이 정하고 원고에는 이름만 남는다(모양 사전과 같은 방식).

### 7.2 흐름

1. 사진함에 사진을 순서대로(또는 찍은 날짜순) 올리고 "책으로 흘려 넣기".
2. 조판기가 펼침면 단위로 나누고 면 틀을 고른다. 기준: ① 잘리는 면적이 가장 작은 틀, ② 리듬 — 같은 틀을 연달아 쓰지 않고 몇 펼침면마다 "펼침면 가득".
3. 의도 지정: 펼침면 틀 바꾸기(지금 사진 수에 맞는 틀만 썸네일로), 같은 펼침면 안에서 자리 바꾸기(끌기), "앞 펼침면으로 / 뒤 펼침면으로", "이 사진 혼자 한 면", 중심점 옮기기.
4. 글은 설명(사진별 또는 펼침면별)과 짧은 글 면. 설명 자리는 틀이 정한다.

### 7.3 첫 출시 데이터 구조에 미리 넣는 것

- `gallery.frame`은 이름(문자열). 칸 모양은 프리셋에.
- 사진함의 `focus`, `takenAt`.
- `[새 펼침면]`(`directive: "newSpread"`) — B에서도 쓴다.
- 조판기 쪽 목록의 펼침면 짝(왼쪽·오른쪽). 펼침면 미리보기가 이미 쓴다.

## 9. 의도 지정 — 손대는 만큼만 어려워지게

| 단계 | 어디서 | 하는 일 |
|---|---|---|
| 0 | — | 아무것도 하지 않음. 모두 자동 |
| 1 | ③ 책 꾸미기 | 사진 크기 `작게 / 보통 / 크게` — 책 전체의 자동 기준 |
| 2 | 미리보기·편집기에서 사진 누르기 | 사진 카드에서 크기·자리 고르기 |
| 3 | 미리보기에서 끌기 | 정해진 자리에 끌어 놓기 |

### 9.1 사진 크기 (책 꾸미기의 쉬운 조정)

| 값 | 자동 크기 |
|---|---|
| 작게 | 가로 사진도 반 폭 |
| 보통 (기본) | 6.1 표 |
| 크게 | 6.1 표 + 장의 첫 가로 사진은 한 면 |

### 9.2 사진 카드

미리보기와 편집기에서 같은 모양이다.

- **크기:** `자동` `본문 폭` `반 폭` `한 면` `펼침면` — 버튼마다 작은 쪽 그림.
- **자리:** `자동` `그 자리` `쪽 위` `쪽 아래` `글 옆` — 크기가 한 면·펼침면이면 숨긴다.
- **자동이 고른 값과 이유:** "자동: 반 폭 — 사진이 작아서 본문 폭이면 흐릿해요", "원래 17쪽인데 자리가 모자라 18쪽 맨 위로 옮겼어요", "펼침면에 두면 빈 면이 생겨서 한 면으로 놓았어요".
- 설명 입력, 사진 바꾸기, 돌리기, 중심점 끌기, "자동으로 되돌리기".
- 고르는 즉시 그 장만 다시 조판한다.

### 9.3 미리보기에서 끌기

- 사진을 집으면 놓을 수 있는 자리가 옅게 나타난다.

  | 놓는 곳 | 저장 |
  |---|---|
  | 문단 사이 가로줄 | 앵커 = 그 앞 문단, 자리 = 그 자리 |
  | 쪽 위·아래 띠 | 앵커 = 그 쪽 첫 문단, 자리 = 쪽 위 / 쪽 아래 |
  | 글 옆 칸 (쪽 왼쪽·오른쪽) | 앵커 = 가까운 문단, 자리 = 글 옆, 쪽 = 왼쪽/오른쪽 |
  | 빈 면 전체 | 크기 = 한 면 |
  | 펼침면 전체 | 크기 = 펼침면 |

- 그 밖의 곳에는 놓을 수 없다.
- 놓으면 알린다: "‘부엌’ 사진을 ‘아궁이 앞에서…’ 문단 뒤, 글 옆으로 옮겼어요 · 되돌리기".
- 다른 쪽으로 옮기는 것은 원고 속 앵커를 옮기는 일이다. 편집기에서도 자리가 바뀐다. 끌기는 같은 장 안에서만 되고, 다른 장으로는 편집기나 사진함에서 옮긴다.
- 사진함에서 미리보기로 바로 끌어 넣을 수 있다.

### 9.4 표시와 되돌리기

- 미리보기의 "사진 보기"에서 작가가 정한 사진에 핀 표시. "이 장 사진 모두 자동으로" 버튼.
- 카드 변경과 끌기는 원고 편집 되돌리기에 들어간다.

## 10. 인쇄

- 종이 끝까지 사진은 재단 여백 3mm까지 늘려 그린다. 확인용 PDF는 판형에서 자른다.
- 펼침면 사진은 인쇄용 PDF(낱쪽)에서 두 쪽으로 나누고 각 쪽에 재단 여백을 붙인다.
- PDF에는 원본 해상도를 넣되, 인쇄 크기에서 600dpi를 넘으면 600dpi로 줄인다(원본은 사진함에 보관).

## 12. 검증

- **조판기 특성 테스트:** 6.1 표의 각 칸, 85% 줄이기와 미루기, 소제목 뒤 2줄, 쪽당 장수, 저절로 묶기, 높이 맞춘 줄 나누기, 한 면·펼침면 홀짝, 의도를 지키지 못할 때의 대체(G4), 글 옆 폭 부족(G6).
- **스냅샷:** 사진이 많은 원고 픽스처 2개(A: 에세이형 10장, B: 여행기형 40장)의 쪽 목록.
- **표기 왕복:** 크기·자리 조합, 사진 묶음, `[새 펼침면]`, `[사진:]` 별칭을 P1·P2에 추가.
- **사용성:** 첫 책 작가 5명에게 사진 10장이 든 원고로 시험. 지표: 배치를 그대로 두고 끝낸 비율, 사진 한 장을 원하는 자리로 옮기는 시간(목표 30초 이내).

## 13. 열린 질문

1. 휴대폰에서 바로 올리기(QR)를 언제 넣나 — 여행기 작가에게 가장 쓸모가 크다.
2. 사진 설명 외에 "찍은 사람·출처" 칸이 필요한가(실용서, 문집).
3. C: 얼굴 인식으로 중심점 자동 잡기, 정사각형 등 사진책 판형, 색 관리(인쇄 색 확인).
4. 85% 줄이기 문턱과 쪽당 장수는 픽스처 원고로 조판해 보고 조정한다.
